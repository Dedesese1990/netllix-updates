# Netllix — معاينة للتصميم

هذه صور تجريبية لترتيب تخصيص الرئيسية والحساب والأجهزة، للمراجعة قبل التنفيذ. لا حسابات حقيقية أو تسجيل Google أو ربط أو فصل أجهزة فعلية في المعاينة. البيانات الظاهرة خيالية. آخر نسخة التطبيق المنشورة تظل build93.
